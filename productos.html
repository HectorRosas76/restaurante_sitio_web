Combo individual Plato principal + acompañamiento + bebida. Combo para compartir Una combinación de diferentes productos pensada para disfrutar entre dos o más personas. Combo familiar Una opción ideal para compartir con familiares o amigos. Combo El Sabroso Una combinación especial de productos seleccionados de nuestro menú. ¿POR QUÉ EL SABROSO? Porque queremos que encuentres todo lo que buscas en un solo lugar. Variedad de sabores, diferentes opciones para todos los gustos y platos ideales tanto para comer solo como para compartir. En El Sabroso puedes venir a disfrutar una hamburguesa, compartir una pizza, probar unas salchipapas, disfrutar unas alitas o simplemente buscar algo diferente para satisfacer tu antojo. NUESTRA PROMESA En El Sabroso trabajamos para ofrecer una experiencia agradable desde que realizas tu pedido hasta el último bocado. Buscamos combinar: Sabor + variedad + calidad + buen servicio Porque para nosotros, un buen restaurante no solamente prepara comida.
